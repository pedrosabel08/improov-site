# src

Código do site (UI + roteamento + integração com conteúdo).

Pastas principais:
- `pages/`: páginas (home, listagem de cases, detalhe do case)
- `components/`: componentes reutilizáveis
- `layouts/`: layouts e estrutura de página
- `features/`: módulos por domínio (ex: cases)
- `styles/`: estilos globais/tokens
- `lib/`: utilitários (format, fetch, helpers)
- `i18n/`: infraestrutura de i18n (carregar textos)
- `types/`: tipos/contratos de dados
